# Review for the test

## GOING TO - UNIT 7
Usamos **going to** para falar sobre o **futuro próximo**: planos ou intenções.

Exemplos:
- **She is going to the supermarket.** (Ela vai ao supermercado.)
- **They are going to travel to the USA.** (Eles vão viajar para os EUA.)
- **Is the boy going to the hospital or the library?** (O menino vai para o hospital ou para a biblioteca?)
- **Are they going to Brazil or the USA?** (Eles vão para o Brasil ou os EUA?)
